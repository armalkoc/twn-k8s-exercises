EXERCISE 7: Port-forward for phpmyadmin

We want to configure port forwarding and forward every request which commes on localhost:8081 to the svc/phpmyadmin-service port 8081 and 
this is done using command:

kubectl port-forward svc/phpmyadmin-service 8081:8081

Now we can access to the phpmyadmi UI using http://localhost:8081 and root username and root password that we configured in the phpmyadmin
deployment.
